  <action>
Create `backend/agents/manager.py` with the AgentManager class that:

1. **Agent instantiation:**
   - Creates instances of MarketAnalystAgent, OrchestratorAgent, TradeExecutorAgent
   - Stores agents in `self._agents` dict keyed by name
   - Tracks supervisor tasks in `self._supervisor_tasks` dict

2. **Staggered startup with health checks (per user decision):**
   - `start_all()` method that starts agents sequentially: Market Analyst -> Orchestrator -> Trade Executor
   - Before starting each agent, verify previous agent is healthy via `_wait_for_agent_health(agent, timeout=5.0)`
   - Health check validates: `agent.is_running` is True and `agent.get_status()["queue_size"] >= 0`
   - Log each agent start with logger.info

3. **Supervisor pattern (per user decision - immediate restart):**
   - `_supervise_agent(agent)` async method that wraps agent.start() in try/except loop
   - On Exception: increment restart_count, log with logger.exception, surface via log_system_event.delay
   - Crash-loop detection: if 3+ restarts in 5 seconds, back off for 10 seconds (per research)
   - On CancelledError: clean stop, break supervisor loop
   - Brief 1 second delay before restart

4. **Graceful shutdown:**
   - `stop_all()` method that cancels all supervisor tasks
   - Calls `agent.stop()` for each agent
   - Awaits all supervisor tasks with `asyncio.gather(..., return_exceptions=True)`
   - Logs shutdown completion

5. **Status accessors:**
   - `get_agent(name)` returns agent by name or None
   - `get_all_status()` returns dict of all agent statuses
   - `_running` flag for supervisor loops
