   ```python
   async def publish_reliable(self, channel: str, message: dict, priority: int = 2) -> bool:
       """
       Publish message to Redis Stream with priority support.

       Priority levels (per user decision):
       - 0: Critical (halt signals, emergency stops)
       - 1: High (rebalance recommendations, risk alerts)
       - 2: Normal (routine insights, research ideas)
       """
   ```
   Implementation:
   - Add metadata: `_timestamp`, `_channel`, `_priority`

   - Call `await self._redis.xadd(stream_key, message)`
   - Check queue depth with `await self._redis.xlen(stream_key)`

   - Log dropped message count for audit (per user decision)
   - Fallback to local if Redis unavailable

3. **Add consume_reliable() method:**
   ```python
   async def consume_reliable(self, channel: str, group: str, consumer: str, callback: Callable) -> None:
       """
       Consume from Redis Stream with consumer group.

       Provides at-least-once delivery via message acknowledgment.
       """
   ```
   Implementation:
   - Create consumer group if not exists (catch BUSYGROUP error)
   - Read from all priority streams in order (p0 first, then p1, then p2)
   - Use xreadgroup with `count=10, block=1000`
   - For each message: call callback, then xack on success
   - On callback exception: log error, message stays unacked for redelivery
   - Check `self._running` in loop

   ```python
   async def stop_consumers(self) -> None:
       """Signal consumers to stop gracefully."""
   ```
   - Sets `self._running = False`

   async def get_queue_depth(self, channel: str) -> Dict[str, int]:
