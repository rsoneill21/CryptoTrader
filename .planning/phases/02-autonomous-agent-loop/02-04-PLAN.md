Update the AgentManager class in `backend/agents/manager.py`:

1. **Add constants:**
   After imports:

   ```python
   HEARTBEAT_CHECK_INTERVAL = 10.0  # Check every 10 seconds
   STALE_THRESHOLD = 30.0  # Claude's discretion: 30 seconds (allows 6 missed beats)
   ```

2. **Add heartbeat monitor task tracking:**
   In __init__ (add to existing attributes):
   ```python
   self._heartbeat_task: Optional[asyncio.Task] = None
   ```

3. **Add check_heartbeats() method:**
   ```python
   async def _check_heartbeats(self) -> None:
       """Monitor loop that checks agent heartbeats and restarts stale agents."""
       while self._running:
           for name, agent in self._agents.items():
               if not agent._running or agent._paused:
                   continue

               try:
                   loop_time = asyncio.get_running_loop().time()
                   age = loop_time - agent._last_heartbeat
               except RuntimeError:
                   continue

               if agent._last_heartbeat > 0 and age > STALE_THRESHOLD:
                   logger.error(
                       f"Agent {name} heartbeat stale ({age:.1f}s > {STALE_THRESHOLD}s), forcing restart"
                   )

                   # Log to system events for dashboard visibility
                   log_system_event.delay(
                       "error",
                       "agent_manager",
                       f"Agent heartbeat stale, forcing restart",
                       {
                           "agent": name,
                           "heartbeat_age_seconds": age,
                           "threshold_seconds": STALE_THRESHOLD,
                       }
                   )

                   # Cancel the supervisor task to trigger restart
                   supervisor_task = self._supervisor_tasks.get(name)
                   if supervisor_task and not supervisor_task.done():
                       # Stop the agent first to reset state
                       await agent.stop()
                       # Supervisor will catch the stop and restart

           await asyncio.sleep(HEARTBEAT_CHECK_INTERVAL)
   ```

4. **Start heartbeat monitor in start_all():**
   At the end of start_all(), after all agents started:
   ```python
   # Start heartbeat monitor
   self._heartbeat_task = asyncio.create_task(self._check_heartbeats())
   logger.info("Heartbeat monitor started")
   ```

5. **Stop heartbeat monitor in stop_all():**
   At the start of stop_all(), before stopping agents:
   ```python
   # Stop heartbeat monitor
   if self._heartbeat_task and not self._heartbeat_task.done():
       self._heartbeat_task.cancel()
       try:
           await self._heartbeat_task
       except asyncio.CancelledError:
           pass
   ```
