## Decisions Made

**Persistence timing:**
- Persist after every signal execution (entry/exit trades) - captures every trade immediately
- Throttle price update persistence (every 10th update) - balance between safety and write load
- Can be tuned with time-based throttling if needed in production

**State serialization:**
- Complete snapshot approach: all positions, cash, P&L, price book, and history in one JSON blob
- Simpler than incremental updates, ensures atomic restore
- Position metadata preserved for exit reasoning and analysis

**Session management:**
- Unique session_id (uuid) generated for each session
- Archive instead of delete for audit trail
- Only one active session at a time (enforced by is_active flag)
