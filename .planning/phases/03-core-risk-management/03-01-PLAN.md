    - Method `validate_trade(db, symbol, quantity, price, side)`: 
      - Checks `trading_control.is_paused()` first. Raises `RiskException` if paused.

      - Checks `max_concurrent_positions` vs open trades.

      - Checks `max_asset_exposure` by summing current open positions for `symbol` + new trade value (quantity * price).
